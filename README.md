# O Aliexpress

Скрипт для Tampermonkey: собирает купоны в центрах купонов AliExpress, хранит список актуальных промокодов и в нужную секунду применяет их на странице оформления заказа.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте ссылку на скрипт — Tampermonkey сам предложит его установить:
   <https://raw.githubusercontent.com/Ovolsan/o-aliexpress/main/o-aliexpress.user.js>

Обновления приходят по той же ссылке: Tampermonkey проверяет её сам и ставит новую версию, когда в репозитории растёт `@version`.

## Возможности

Меню открывается квадратной кнопкой с билетом в левом нижнем углу страниц AliExpress. Те же пункты есть в меню самого Tampermonkey.

- **Сбор купонов (центр купонов)** и **Сбор купонов 2** — открывают центр купонов и нажимают «Получить» по одному, со случайными паузами, пакетами и длинным перерывом каждые 60–80 купонов. Если AliExpress показывает проверку безопасности или CAPTCHA, сбор останавливается.
- **Актуальные промокоды** — ваш список кодов. Код копируется по клику, список можно изменить; если вставить пост из канала целиком (`$3/$15 (20.00%) → UAD1103`), останутся только коды.
- **Промокоды по таймеру** — на странице товара скрипт нажимает «Купить сейчас», на странице оформления открывает панель. В заданную секунду он по очереди вводит коды и нажимает «Применить», а у каждого кода показывает результат. Время сверяется с часами сервера AliExpress.

## Что важно знать

- Скрипт обращается только к AliExpress. Сторонних серверов и партнёрских ссылок нет.
- До старта по таймеру держите вкладку на экране: в фоне браузер замедляет таймеры.
- Не вводите слишком много промокодов подряд: AliExpress может показать CAPTCHA, её нужно пройти вручную.
